# social_bias_neurons
This is the GitHub repository for Social Bias Neurons in Multilingual Models: A Mechanistic Interpretability Analysis--which has been accepted for publication in the Findings of the European Associaton for Computational Linguistics 2027 (EACL2027).

The code for Activation Probability Entropy (APE) is heavily based on https://github.com/RUCAIBox/Language-Specific-Neurons

The code for Integrated Gap Gradients (IGG) is heavily based on https://github.com/theNamek/Bias-Neurons
